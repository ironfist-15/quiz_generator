Quiz Generator
You can create quizzes with customized questions and categories, take quizzes to test your knowledge, and even manage questions by adding or deleting them.

It uses springboot in the backend ,postgre sql database, html,css and js in the frontend.
It demonstrates concepts like CRUD operations and Many to Many mapping in the backend.
